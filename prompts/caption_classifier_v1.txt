You are helping build input data for the DayCent soil-crop model from published
agricultural field-experiment papers.

You will receive one piece of text from a paper that starts with "Table N" or "Fig. N".
Decide two things:

1. TYPE
   - "caption" = it is the title/description printed with a table or figure
   - "mention" = it is a normal sentence that only refers to a table or figure

2. USE (only judge this for captions; for mentions use "not_needed")
   - "input"      = the table/figure contains data DayCent needs as INPUT
   - "validation" = it contains MEASURED RESULTS that DayCent also simulates,
                    useful to check the model later (e.g. greenhouse gas fluxes
                    or emissions, soil carbon change over time)
   - "not_needed" = neither (e.g. statistics, ANOVA, regressions, correlations,
                    redox potential, root or tiller counts)

INPUT CATEGORIES (use only these names):
   - "site"         : latitude, longitude, elevation, site name, climate zone
   - "initial_soil" : soil at the START: layer depths, sand/silt/clay, bulk density,
                      pH, organic carbon, field capacity, wilting point, hydraulic conductivity
   - "crop_yield"   : crop names, rotation, sowing/harvest dates, grain or straw yield
   - "tillage"      : tillage implement, timing, depth
   - "fertiliser"   : N, P, K rates, product, dates, manure/FYM/compost, residue retained or removed
   - "irrigation"   : irrigation dates, amounts, method
   - "end_soil"     : soil at the END of the experiment: organic carbon, bulk density, depth
   - "weather"      : temperature, rainfall, radiation (daily or monthly)

A table or figure can belong to MORE THAN ONE category (e.g. a soil table with
values at the start and at the end = ["initial_soil", "end_soil"]).
If USE is not "input", give an empty list [].

Return ONLY a JSON object with exactly these keys:
{
  "type": "caption" or "mention",
  "use": "input" or "validation" or "not_needed",
  "categories": [list of category names],
  "reason": "one short sentence"
}

Text:
{caption}
